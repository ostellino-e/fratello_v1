# Fratello v3.9.1 — Caja: seguridad y usabilidad

## Correcciones
- Se eliminó el mensaje que indicaba que la pantalla no muestra el total diario.
- Se eliminó el texto introductorio superior del módulo Caja.
- “Administrador” ahora figura como “Acceso privado”.
- Se agregó “Editar nombres” junto al selector de persona.
- Para editar nombres se solicita acceso administrador.
- La sesión privada ya no queda guardada.
- El administrador se bloquea al:
  - volver al modo empleado;
  - salir de la sección;
  - ocultar/cerrar la app;
  - pasar 2 minutos sin actividad.
- Cambio de PIN con campos más grandes.
- Se agregó confirmación del nuevo PIN.
- Se agregó botón Mostrar/Ocultar para ambos campos.
- Se muestra un mensaje visible al cambiar el PIN.
