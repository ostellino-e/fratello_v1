# Fratello v3.9.4C.1 — Administración Financiera

## Nuevo módulo privado
Se agregó la sección **Administración**, protegida con el mismo PIN privado de Caja.

## Ingresos
- Toma automáticamente los cierres de Caja.
- Permite cargar clientes que pagan por fuera: Giuli, Luis, Sindicato, Líbano u otros.
- Registra efectivo, transferencia, Mercado Pago, cheque u otro medio.
- Permite marcar ingresos como cobrados o pendientes.

## Gastos
- Los gastos cargados por las chicas en el cierre de Caja aparecen automáticamente.
- No es necesario volver a cargarlos, evitando duplicados.
- Permite cargar gastos externos separados por:
  - Empleados
  - Proveedores / Insumos
  - Panadería
  - Gastos generales
  - Impuestos y servicios
  - Préstamos
  - Ahorro / Inversión
  - Otros
- Permite marcar gastos como pagados o pendientes.

## Presupuesto
- Presupuesto mensual por concepto y categoría.
- Comparación entre presupuestado, gastado y diferencia.
- Barra de porcentaje utilizado.

## Resumen
- Ingresos totales.
- Gastos totales.
- Resultado estimado.
- Compromisos pendientes.
- Separación de Caja e ingresos externos.

## Privacidad
- La información no se muestra hasta ingresar el PIN.
- Se bloquea automáticamente después de 3 minutos sin actividad.
- Usa el mismo PIN de acceso privado de Caja.
