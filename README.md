# Fratello v3.9.3A — Correcciones operativas

## Incluido
1. La fecha elegida para pedidos futuros ya no vuelve automáticamente a la fecha actual.
2. Los tickets usan precios de respaldo cuando Fratello, Giuliano u otro cliente no tiene una lista específica completa.
3. Todos los días de la sección Pedidos aparecen cerrados al entrar.
4. Los pedidos fijos de fechas futuras quedan dentro de una pestaña plegable.
5. Se agregó el botón Ver en pedidos futuros.
6. El formulario de Caja se limpia después de confirmar el cierre.
7. El botón Ver detalle del Libro Diario usa un evento directo y estable.
8. La información privada se borra y oculta completamente al cerrar el acceso administrador o volver al inicio.
