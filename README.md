# Fratello v5.1.4 — Caja editable y siete días de Pedidos

## Caja
- El botón Editar ahora abre el editor dentro del turno seleccionado.
- Se pueden modificar persona, efectivo, transferencias, observaciones y gastos.
- Se agregó el botón Eliminar para cada cierre de turno.
- Eliminar solicita confirmación y actualiza los totales del día y del mes.
- Se conservan el Libro de Caja y los datos existentes.

## Pedidos
- La pantalla muestra siempre siete días corridos desde el día operativo actual.
- Ya no queda limitada al domingo.
- Al comenzar una nueva semana, el lunes y los días siguientes aparecen automáticamente.
- Los pedidos fijos se cargan para las nuevas fechas como antes.
