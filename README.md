# Fratello v5.0.0 — Mejora visual de Administración

## Cambios
- Administración reorganizada en una grilla de dos columnas.
- Botones principales más grandes, uniformes y fáciles de identificar.
- Mejor espaciado, bordes redondeados, sombras y respuesta al tocar.
- Ajustes para pantallas pequeñas.

## Alcance
Esta versión modifica únicamente la presentación visual de Administración.
No cambia Firebase, pedidos, tickets, caja ni la lógica de datos.
