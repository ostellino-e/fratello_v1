# Fratello v3.6 — Pedidos para hoy

- Nueva subsección independiente dentro del módulo Pedidos.
- Permite cargar cliente, detalle y hora de entrega.
- Permite editar, eliminar y marcar como entregado.
- Ordena primero los pendientes y luego por horario.
- Se reinicia automáticamente con la jornada de las 06:00.
- Los pedidos del día se guardan separados de los pedidos de producción.
- No cuentan en producción, diferencias, resumen, pedidos futuros ni WhatsApp.
